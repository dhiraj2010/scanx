# ScanX

Chartink-style stock screener app for Android: Nifty 50/500, Midcap 150, Smallcap 250 and S&P 500, daily and weekly bars, saved and custom scans, charts.

**Download the app:** open the [Releases page](../../releases) on your Android phone, tap `ScanX.apk`, then install it (allow installing from this source when asked).

Every change pushed to this repository builds a new APK automatically (see the Actions tab).

Educational tool, not investment advice. Prices from Yahoo Finance (end-of-day or delayed).
